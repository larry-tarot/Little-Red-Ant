# 同步频率与限制

为了避免触发小红书风控，小红蚁提供了同步频率、分析次数等限制配置。

## 配置项说明

| 配置项 | 说明 | 推荐值 |
|---|---|---|
| 对标账号自动更新周期 | 每隔多久自动刷新一次对标数据 | 4 小时 |
| 每日 AI 分析次数上限 | 每个账号每天最多分析多少次 | 20 次 |
| 每日笔记生成次数上限 | 每个账号每天最多生成多少篇笔记 | 50 次 |
| 评论同步间隔 | 每隔多久同步一次评论 | 15 分钟 |

## 修改方式

1. 进入 **设置** → **系统配置**。
2. 找到对应配置项。
3. 输入新的数值。
4. 点击 **保存**。

!!! warning "不建议过小"
    同步频率过小（如 5 分钟）容易被平台判定为异常访问，建议保持默认值或更大间隔。
