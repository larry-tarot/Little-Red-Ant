# 批量更新对标数据

当你监控的对标账号较多时，可以批量刷新数据，无需逐个点击。

## 操作步骤

1. 进入 **对标账号监控** 页面。
2. 点击账号卡片左上角的复选框，或点击 **全选**。
3. 页面底部会出现批量操作栏。
4. 点击 **批量更新**。

![批量更新](../assets/screenshots/competitor-monitor.png)

## 注意事项

- 批量更新会按顺序逐个账号抓取，避免同时触发反爬。
- 更新完成后，页面会显示成功/失败数量。
- 失败的账号可以单独点击 **重新更新**。

## 自动更新

除了手动刷新，系统还支持定时自动更新。配置方式请参考 [同步频率与限制](../settings/cron-and-limit.md)。
