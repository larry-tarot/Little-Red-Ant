# 切换活跃账号

小红蚁支持同时管理多个小红书账号，但同一时间只能有一个账号处于“活跃”状态，用于数据抓取和内容发布。

## 切换方式

### 方式一：在账号矩阵切换

1. 进入 **账号矩阵**。
2. 找到目标账号卡片。
3. 点击卡片上的 **设为活跃** 按钮。

![设为活跃](../assets/screenshots/account-matrix.png)

### 方式二：在顶部状态栏切换

桌面端底部状态栏会显示当前活跃账号，点击可快速切换。

## 活跃账号的作用

- **数据抓取**：对标监控、热门笔记抓取使用活跃账号的 Cookie。
- **内容发布**：发布笔记时使用活跃账号。
- **评论同步**：同步该账号下的评论和私信。

!!! tip "建议"
    如果某个账号频繁触发风控，可以临时切换到其他账号继续工作。
