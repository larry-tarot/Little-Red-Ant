# 绑定小红书账号（发布权限）

发布权限允许小红蚁代替你发布笔记、管理草稿。相比浏览权限，发布权限对账号安全要求更高。

!!! warning "安全提醒"
    发布权限会涉及内容发布操作，请确保只在你信任的设备和网络环境下绑定。

## 前置条件

- 已完成 [浏览权限绑定](bind-preview.md)。
- 该账号状态为 **可预览** 或 **可发布**。

## 操作步骤

1. 进入 **账号矩阵**。

![账号矩阵](../assets/screenshots/account-matrix.png)

2. 找到目标账号，点击 **绑定发布**。
3. 按提示扫码登录（流程与浏览权限相同）。
4. 在手机上点击 **确认登录**。
5. 等待状态变为 **可发布**。

## 状态说明

| 状态 | 含义 |
|---|---|
| 可预览 | 只能抓取数据，不能发布 |
| 可发布 | 既能抓取数据，也能发布笔记 |

## 发布内容时如何选择账号？

在 [草稿与发布](../content/drafts.md) 页面，系统会让你选择当前**活跃账号**。只有状态为 **可发布** 的账号才会出现在可选列表中。
