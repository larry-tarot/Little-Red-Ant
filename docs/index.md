# 小红蚁使用文档

欢迎来到小红蚁文档中心。这里汇集了安装、配置、日常使用与问题排查的完整指南。

## 小红蚁是什么？

小红蚁是一款面向小红书创作者和运营团队的一站式工具，帮助你：

- **账号管理**：集中管理多个小红书账号，快速切换活跃账号。
- **内容创作**：利用 AI 生成笔记、视频脚本、封面图，并提供可视化编辑器。
- **对标监控**：添加竞品/对标账号，AI 自动拆解爆款策略和数据趋势。
- **互动管理**：同步评论、私信，提供 AI 回复建议。
