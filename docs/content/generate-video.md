# 生成视频脚本

除了图文笔记，小红蚁还支持生成短视频脚本，包括分镜、台词、画面描述等。

## 操作步骤

1. 进入 **内容创作** 页面。
2. 切换到 **视频脚本** 标签。
3. 输入视频主题和关键信息：
   - 视频主题
   - 目标时长
   - 风格（口播、Vlog、教程等）
   - 必须提到的卖点

![视频脚本表单](../assets/screenshots/video-script-form.png)

4. 点击 **生成脚本**。

## 脚本结构

生成的脚本通常包含：

| 部分 | 说明 |
|---|---|
| 开场 Hook | 前 3 秒吸引注意力的内容 |
| 正文 | 核心信息，分点讲解 |
| 画面描述 | 每个镜头该拍什么 |
| 口播文案 | 主播需要说的台词 |
| CTA | 结尾引导点赞/关注/评论 |

## 下一步

脚本生成后，可以：

- 复制脚本到剪映/PR 拍摄剪辑
- 保存为草稿
- 一键生成配套封面
