# 封面编辑器

封面是小红书笔记点击率的关键。小红蚁内置封面编辑器，支持添加文字、贴纸、滤镜等基础功能。

## 打开方式

1. 在 [生成笔记](generate-note.md) 或 [生成视频脚本](generate-video.md) 完成后，点击 **生成封面**。
2. 或者在左侧导航进入 **封面编辑器**。

## 主要功能

- **上传图片**：支持本地上传或从 AI 生成图中选择。
- **文字编辑**：修改标题、副标题、标签字体样式。
- **滤镜/调色**：快速调整封面色调。
- **尺寸裁剪**：小红书封面推荐 3:4 竖图。

> 封面编辑器在生成笔记/视频脚本后通过 **生成封面** 按钮唤起，支持文字、贴纸、滤镜与 3:4 裁剪。

## 导出与使用

编辑完成后，点击 **导出图片**，系统会生成高清封面。生成笔记时可以在图片列表中选择该封面。
