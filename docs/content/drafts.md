# 草稿与发布

生成的内容可以先保存到草稿箱，编辑完善后再发布。

## 草稿箱

1. 点击左侧导航 **草稿箱**。
2. 查看所有已保存的草稿。
3. 点击草稿进入编辑页面。

![草稿箱](../assets/screenshots/drafts.png)

## 发布流程

1. 编辑好内容后，点击 **发布**。
2. 选择发布账号（仅显示 **可发布** 状态的账号）。
3. 确认标题、正文、图片。
4. 点击 **立即发布**。

!!! tip "定时发布"
    如需定时发布，可设置发布时间。系统会在指定时间自动调用小红书接口发布。

## 发布失败排查

如果发布失败，请检查：

- 活跃账号是否为 **可发布** 状态
- 图片是否符合小红书格式要求
- 内容是否包含敏感词
- 该账号当天是否已达到发布频次限制
