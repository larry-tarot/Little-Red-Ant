# 常见问题

## 通用问题

### Q：小红蚁支持 macOS 吗？

A：目前主要支持 Windows。macOS 和 Linux 理论上可以运行，但尚未完整测试。

### Q：可以同时管理多少个账号？

A：没有硬性上限，取决于你的设备性能和账号风控情况。建议每个设备管理 5~10 个账号。

### Q：数据存储在哪里？

A：默认使用本地 SQLite 数据库，路径在项目目录下。可以在配置中切换为其他数据库。

## 账号绑定问题

### Q：为什么扫码后状态还是未授权？

A：请确认手机上点击了 **确认登录**。只扫码不确认无法获取有效 Cookie。

### Q：二维码过期了怎么办？

A：关闭弹窗，重新点击 **绑定浏览** 生成新二维码。

### Q：可以绑定别人的账号吗？

A：技术上可以，但需要对方配合扫码。不建议绑定非本人账号，存在合规和安全风险。

## 内容生成问题

### Q：AI 生成内容会重复吗？

A：AI 会根据你输入的主题、关键词、风格生成内容，相同输入可能产生相似输出。建议每次输入差异化的要求。

### Q：生成的内容可以直接发布吗？

A：建议先人工审核，特别是涉及品牌、医疗、金融等敏感领域的内容。

## 对标监控问题

### Q：为什么对标数据没有更新？

A：检查：

1. 活跃账号是否为 **可预览** 或 **可发布** 状态
2. 对标账号是否设置为公开可见
3. 是否达到同步频率限制
4. 后端日志是否有反爬拦截提示
